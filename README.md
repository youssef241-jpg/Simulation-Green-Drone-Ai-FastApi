Smart Agriculture Drone API

Smart Agriculture Drone API is a Python-based training project designed to simulate the backend system of an intelligent agricultural drone.

The project uses FastAPI to build RESTful APIs for managing drone information, sensor readings, agricultural missions, and simulated AI analysis results. It also includes an interactive dashboard built with Streamlit to monitor drone activity, visualize sensor data, manage missions, and display AI detection results.

Key Features

- Drone Management (Create, Read, Update, Delete).
- Sensor Data Collection and Monitoring.
- Agricultural Mission Management.
- Simulated AI Analysis Results.
- Interactive Dashboard for monitoring and visualization.
- Data Validation using Pydantic.

Technologies Used

- Python
- FastAPI
- Pydantic
- Streamlit
- Requests

Project Purpose

This project was developed to practice backend development, REST API design, data validation, and frontend-backend communication using Python.

Note: This is a simulation and training project. It does not currently include a real AI model, physical drone integration, or database storage. All data is stored temporarily in memory.
